# Обращение в поддержку VK

Кому: `devsupport@corp.vk.com`
Тема: `Доступ к groups.removeUser для мини-приложения 54720386`

## Чем это письмо отличается от прошлого

Прошлое просило «добавить scope `groups` приложению VK ID 54634256». Ответить на
него было нечего: в VK ID scope `groups` не существует, там всего три доступа —
`vkid.personal_info`, `email`, `phone`. Запрос выглядел как ошибка, и его,
судя по всему, просто отложили.

Теперь спрашиваем о том, что существует: `groups` уже выдан, метод уже вызван,
получен конкретный отказ с конкретной причиной. На такой вопрос ответ есть в
любом случае — либо доступ, либо название поддерживаемого способа.

## Текст

> Здравствуйте!
>
> Прошу разъяснить поддерживаемый способ программного удаления участников
> собственного сообщества.
>
> Исходные данные:
> — сообщество 236838246, я его администратор;
> — мини-приложение 54720386, создано мной;
> — право `groups` успешно получено через `VKWebAppGetAuthToken`, в ответе
> `scope` содержит `groups`.
>
> При вызове метода с этим ключом приходит отказ:
>
> `groups.removeUser` → `Access denied: no access to call this method.
> Permission to perform this action is denied for non-standalone applications`
>
> Другие проверенные варианты также недоступны:
> — ключ сообщества с правом `manage` → `error 27: Group authorization failed:
> method is unavailable with group auth`;
> — ключ VK ID (приложение 54634256) → `error 15` на `groups.removeUser`
> и `error 1051` на `groups.banUser`;
> — создать приложение типа Standalone в кабинете невозможно, такой тип
> отсутствует в списке.
>
> Задача — автоматическая модерация собственного сообщества: удаление и
> блокировка участников по обращению из внутреннего сервиса. Сторонние
> приложения и чужие client_id не используем принципиально.
>
> Прошу либо предоставить приложению 54720386 доступ к методам
> `groups.removeUser` и `groups.ban`, либо указать, какой тип приложения и
> способ авторизации сейчас поддерживается для этой задачи.
>
> С уважением,
> [имя], администратор сообщества 236838246

## Что приложить

- Скриншот ответа `VKWebAppGetAuthToken`, где в `scope` виден `groups` —
  он снимает вопрос «а выдано ли право».
- Скриншот ошибки метода.

Оба видны в мини-приложении: текст ошибки выводится в блоке 3 и дублируется
в лог внизу страницы.

## Если ответа не будет

Прошлое письмо осталось без ответа больше месяца. Если и это повиснет, остаются
только варианты без API — ручная модерация штатными средствами VK. Обходы через
токены сторонних клиентов (Kate Mobile, vfeed, Prizma) рассматривать не стоит:
с мая 2026 за них выдают блокировки аккаунтов.
